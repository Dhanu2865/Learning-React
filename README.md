# Learning React

This repository contains resources, examples, and code snippets to help you learn **React**, a popular JavaScript library for building user interfaces.

## Topics Covered

### 1. React Fundamentals
- Introduction to React
- How React works under the hood
- Understanding components and rendering

### 2. Creating React Elements
- Initializing projects using **Vite**
- Working with **JSX** syntax
- Creating and rendering React components

### 3. Writing React Components
- Displaying lists and dynamic content
- Working with images
- Using **Fragments** to group elements

### 4. Handling State
- Managing state with **useState**
- Using **useReducer** for complex state logic
- Handling side effects with **useEffect**

### 5. React Server Components
- Setting up projects with **Next.js**
- Understanding and building Server Components

### 6. Asynchronous React
- Fetching data from APIs
- Passing data through props
- Creating and using **Server Actions**
